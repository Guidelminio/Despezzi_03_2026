# Skills de agentes

Coleção de skills derivada do repositório [WebWakaHub/manus-agency-skills](https://github.com/WebWakaHub/manus-agency-skills), importada do commit `2a7d53c` da branch `main`.

Foram encontrados **71 arquivos `SKILL.md`** no commit de origem; o README da origem declara 72. Todas as 71 skills presentes foram incluídas.

## Compatibilidade e proveniência

- Cada skill está em `skills/<slug>/SKILL.md`.
- Os cabeçalhos foram normalizados para o formato Manus: nomes em kebab-case, licença `MIT` e descrições com contexto de uso.
- Nos 68 arquivos com frontmatter, os campos de origem `color` e `tools` foram preservados dentro de `metadata` como `source_color` e `source_tools` quando existentes. Esses metadados são informativos e não concedem permissões de ferramenta.
- Três skills de estratégia não tinham frontmatter; foram acrescentados cabeçalhos mínimos. Os corpos das skills foram mantidos.
- A licença MIT e a atribuição do projeto original estão em [`LICENSE`](./LICENSE). A coleção deriva de [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents).
